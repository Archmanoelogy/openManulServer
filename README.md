# OpenManulServer

Creating a server to present [OpenManul](https://github.com/Archmanoelogy/openManul) Data.

# Quick Start

``` shell
cd src/python-server
python3 -m server
```

Then, use browser visit `http://127.0.0.1:8080/`, or use your own domian name `http://{domain_name}:8080/`.

# Site Map

Take `http://open-manul.apiglio.top` as an example:

|Site|Url|
|---|---|
|Home Page / Manul List|`http://open-manul.apiglio.top` <br> `http://open-manul.apiglio.top/list`|
|Manul Info|`http://open-manul.apiglio.top/info/{ID}`|
|Manul Tree|`http://open-manul.apiglio.top/tree/{ID}`|
|Manul Timeline|`http://open-manul.apiglio.top/timeline/{ID}`|
|Manul Map|`http://open-manul.apiglio.top/map/{Zoo-ID}`|
